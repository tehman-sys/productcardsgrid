# Product Card Grid

A responsive product card grid built with HTML, Tailwind CSS, and vanilla CSS Grid — practicing layout fundamentals through a real UI pattern.

**Live demo:** [Add your GitHub Pages link here]

## What this project covers

- CSS Grid layout with `grid-cols-*`
- Responsive breakpoints (`md:`, `lg:`) for adaptive column counts
- `object-cover` for consistent image cropping across varying aspect ratios
- Card component styling (shadows, rounded corners, spacing)
- Button hover states and transitions

## Tech stack

- HTML5
- Tailwind CSS (via CDN)

## About

Third project in a self-directed series practicing Tailwind/HTML/CSS unaided. Previous projects: a personal profile card and a pricing table, both deployed to GitHub Pages.
